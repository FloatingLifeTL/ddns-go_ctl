# v2.8.0

## 概要

`ddns-go_ctl` 2.8.0 完成源码结构标准化：引入接口隔离与依赖注入，可调参数收敛为单一来源，界面与业务解耦。菜单按键、部署方式、启动参数和运行数据格式不变。

## 变更

- 新增 `Settings`，作为 DDNS-GO 启动参数与可调参数的唯一来源。
- 以 `typing.Protocol` 声明组件边界：进程操作、端口查询、运行状态存储、日志管理、子进程创建、渲染上下文、控制台输出和按键读取。
- 上述接口提供默认实现（Win32 进程操作、`netstat.exe` 端口查询、文件状态存储、文件日志管理、`subprocess.Popen` 封装），`DdnsController` 支持 keyword-only 依赖注入替换。
- `DdnsController` 的可调参数属性改为只读并委托 `Settings`，避免两套状态漂移。
- 控制台渲染与日志查看会话依赖输出协议，不再反向依赖具体控制器实现。
- 新增 `tests/test_interface_isolation.py` 专项测试，覆盖协议一致性、`Settings` 单一来源和依赖注入装配。
- 开发与 CI 检查统一为 `python -m unittest discover -s tests -p "test_*.py" -v`，一次跑完 `tests/` 下全部测试模块。
- 补全接口方法的文档块，统一注释表述。
- 新增 `scripts/checksums.ps1`，按 GNU coreutils 格式生成与校验发布产物的 `SHA256SUMS.txt`；发布资产的 SHA-256 改由清单记录，不再写进发布说明。

## 兼容性

- 菜单按键、启动参数、日志规则、运行目录布局和 `ctl-data/` 数据格式不变。
- 不新增第三方依赖，仍只使用 Python 标准库。
- 支持系统与运行基线不变：Windows x86_64，CPython 3.11 或更高版本。

## 验证

- 当前测试共 178 项（`test_ddns_go_ctl.py` 161 项，`test_interface_isolation.py` 17 项），全部通过。
- `./scripts/release-notes.ps1 -Check` 通过。
- 自动化测试不启动 DDNS-GO 本体，不触发动态 DNS 更新。
- 冻结版冒烟实测：官方 `ddns-go.exe` v6.17.7、新默认配置，无实际 DNS 变更；退出码 0，`_MEI...` 临时目录创建与清理正常。
- 内嵌源码可导出为 `source/ddns-go_ctl.py`，150,496 字节，与 `src/ddns-go_ctl.py` 逐字节一致。
- 菜单退出后 DDNS-GO 与转发器进程存活；重启菜单识别双 PID；停止后进程数归零。
- 端口被占用时拒绝启动，且不写入运行状态。
- PE 导入依赖仅 ADVAPI32、KERNEL32、USER32。
- 校验清单通过 `sha256sum --check --strict`（资产以最终发布名就位校验）。
- 未验证项：无 Python 的干净目标机、资源管理器双击启动、非 ASCII 路径、异常退出后的临时目录残留。
