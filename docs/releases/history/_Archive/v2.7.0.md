# v2.7.0

## 概要

`ddns-go-ctl` 2.7.0 面向 DDNS-GO 提供 Windows 外部管理工具，支持启动、停止、状态查看、管理页面和运行时日志查看，并提供无需安装 Python 的 Windows x64 单 EXE。

## 变更

- 将菜单和日志查看页重构为标准库 TUI 状态、会话和动作分发架构。
- 保留现有按键、全屏界面、颜色、日志翻页、末尾跟随、跳行、跳页、清理和刷新行为。
- 不引入第三方 Python 依赖。
- 保留 Windows Job Object 进程托管、运行状态校验、日志转发和进程身份核验。
- 提供 Windows x64 发布版 `ddns-go_ctl.exe`，运行无需安装 Python。
- 仍不包含、不代理分发 `ddns-go.exe`，必须从 DDNS-GO 官方 Releases 获取。

## 使用

- 将 `ddns-go_ctl.exe` 与官方 `ddns-go.exe` 放入同一目录。
- 双击或运行 `ddns-go_ctl.exe`。
- 方法二：使用源码目录中的 `ddns-go_ctl.py`，需要 CPython 3.11 或更高版本。
