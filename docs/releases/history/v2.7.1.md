# v2.7.1

## 概要

`ddns-go_ctl` 2.7.1 整理公开仓库结构，并明确源码入口应按“同目录运行”的方式部署到 DDNS-GO 所在位置。DDNS-GO 管理行为、外部命令和原有同目录运行模型不变。

## 变更

- 生产源码从 `scripts/ddns-go_ctl.py` 移至 `src/ddns-go_ctl.py`。
- 源码入口不理解为仓库内运行位置；实际部署时，将 `ddns-go_ctl.py` 和配套批处理移动到 `ddns-go.exe` 所在目录。
- 公开社区文档归入 `.github/`，项目说明、版本和发布说明归入 `docs/`。
- 测试移入 `tests/`，GitHub Actions 测试命令同步更新。
- 发布说明按版本拆分到 `docs/releases/`，当前版本为 `v2.7.1`。
- `README.md`、`docs/project.md`、启动入口和测试路径同步更新。

## 使用

源码方式：

1. 从 `src\` 取出 `ddns-go_ctl.py`；如使用批处理，同时取出 `ddns-go_ctl_py-run.bat`。
2. 将脚本和配套批处理移动到 `ddns-go.exe` 所在目录。
3. 在该目录运行 `python ddns-go_ctl.py`，或双击 `ddns-go_ctl_py-run.bat`。

不要把官方 `ddns-go.exe` 放回源码仓库的 `src\`。
