# v2.6.3

## 概要

`ddns-go-ctl` 2.6.3 是面向 DDNS-GO 的 Windows 外部管理工具，提供启动、停止、状态查看、管理页面和运行时日志查看。

## 说明

- 本项目不是 DDNS-GO 的源码 Fork。
- 不修改、不包含、不分发 DDNS-GO 源码或 `ddns-go.exe`。
- 运行时需要从 DDNS-GO 官方 Releases 获取可执行文件。

## 发布内容

- 管理脚本源码
- Windows 双击启动入口
- 标准库 unittest 测试
- MIT 许可证
- 上游第三方许可声明
- 安全与贡献说明
- GitHub Actions 测试工作流

## 验证

- 当前测试共 161 项，全部通过。
